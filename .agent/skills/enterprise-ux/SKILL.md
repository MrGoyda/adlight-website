# ⚡ Enterprise UX & Power User Mechanics

Этот скилл предназначен для перевода интерфейсов из категории "веб-сайтов" в категорию "Профессиональный софт" (Pro Tools) для пользователей, работающих в системе по 8+ часов в день (ERP, CRM).

## 1. Профессиональная навигация (Keyboard-First & Command Palette)
Все критические интерфейсы должны управляться с клавиатуры (мышь — второстепенный инструмент).
- **Command Palette (Cmd+K):** Внедрять `cmdk` для глобального поиска и быстрых действий.
- **Горячие клавиши (Hotkeys):** Использовать хуки (например, `react-hotkeys-hook`):
  - `Cmd + Enter` / `Ctrl + Enter` — отправка любой формы.
  - `Esc` — закрытие модалки/дропдауна или сброс выделения.
  - `Cmd + S` — сохранение драфта.
- **Навигация по таблицам:** Поддержка стрелок (Arrow Keys) и выделения строк через `Shift + Click`.

## 2. Плавная адаптивность (Fluid Layout & Typography)
Запрещено использовать дискретные медиа-запросы (`md:`, `lg:`) для базовых отступов и крупных заголовков.
- **CSS Clamp:** Использовать `clamp()` для плавной генерации размеров (`text-[clamp(1.5rem,5vw,3rem)]`).
- **Автоматизация:** При возможности настроить Tailwind плагин для Fluid Typography, чтобы классы масштабировались плавно, сохраняя пропорции "Золотого сечения".

## 3. Строгое форматирование локали (Currency & Dates)
Строгий запрет на ручное форматирование валют, чисел и дат конкатенацией строк. Финансовый контекст требует точности.
- **Валюта и числа:** Всегда использовать нативный `Intl.NumberFormat`.
  ```typescript
  export const formatCurrency = (amount: number, locale = 'en-US', currency = 'USD') => {
    return new Intl.NumberFormat(locale, {
      style: 'currency', currency: currency, maximumFractionDigits: 0
    }).format(amount);
  };
  ```
- **Относительное время:** Для логов и событий использовать относительное время через `date-fns`.

## 4. Оптимистичные Мутации (Zero-Latency UI)
Пользователь не должен знать, что запрос отправляется. Интерфейс должен реагировать мгновенно.
- **React 19 `useOptimistic`:** В Next.js 15 при работе с Server Actions обязательно внедрять этот хук. UI меняется мгновенно (Optimistic State), а если сервер возвращает ошибку — состояние тихо откатывается с показом Toast.
- **Дебаунс ввода (Debounced Autosave):** В текстовых полях ERP минимизировать использование кнопки "Сохранить". Сохранять данные автоматически через `useDebounce` (задержка 500-1000мс после окончания печати).
