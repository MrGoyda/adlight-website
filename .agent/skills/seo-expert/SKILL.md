# 🚀 SEO Expert & Search Authority

Этот модуль превращает сайт из красивой картинки в лидера поисковой выдачи. Мы используем только "белые" методы оптимизации, современные API Next.js 15 и глубокую разметку Schema.org.

## 1. Динамические Метаданные (Next.js 15 Metadata API)
- **Централизация**: Все метаданные должны генерироваться через утилиту `constructMetadata` в `src/lib/seo.ts` (или аналогичном пути).
- **Локализация**: Каждая страница должна иметь уникальные `title` и `description`, адаптированные под целевой регион и язык.
- **Favicons & PWA**: Всегда включать поддержку манифеста, иконок для Apple и превью для соцсетей (OpenGraph/Twitter).
- **Async Metadata**: В Next.js 15 функция `generateMetadata` ОБЯЗАНА `await`ить `params` перед использованием.

## 2. Структурированные Данные (JSON-LD / Schema.org)
- **Business/Organization**: Генерировать разметку `LocalBusiness` или `Organization` с точными координатами, адресом и телефоном для каждой локации.
- **FAQPage**: Автоматически генерировать схему для блоков "Вопрос-Ответ", чтобы занимать больше места в выдаче.
- **BreadcrumbList**: Строгое соблюдение иерархии в разметке хлебных крошек.
- **Интеграция**: Схемы инжектируются через компонент `JsonLd` или напрямую в `<head>` через API Next.js.

## 3. Оптимизация Core Web Vitals (LCP, CLS, INP)
- **Image Priority**: Первый экран (Hero) ОБЯЗАН использовать `priority` в `next/image` для минимизации LCP.
- **Layout Shift (CLS)**: Всегда задавать `width/height` или `aspect-ratio` для изображений и видео-контейнеров.
- **Font Optimization**: Использовать `next/font` с `display: swap` для предотвращения невидимого текста (FOIT).
- **Video Performance**: Фоновые видео должны иметь `preload="none"` или `muted playsInline` для корректного старта без блокировки основного потока.

## 4. Семантика и Доступность (A11y)
- **Иерархия заголовков**: Строго один `<h1>` на страницу. Соблюдать порядок `h2 -> h3` без пропусков.
- **Alt-тексты**: Каждое смысловое изображение должно иметь осмысленный `alt`. Декоративные элементы — `alt=""`.
- **Descriptive Links**: Избегать ссылок типа "Подробнее" без контекста. Использовать `aria-label` для уточнения.

## 5. Локальное SEO (Local Presence)
- **NAP Consistency**: Имя, Адрес и Телефон должны совпадать во всех блоках сайта и в разметке Schema.org.
- **City Context**: Использовать гео-ключевые слова в заголовках и текстах (например, "в [Городе]", "[Услуга] в [Регионе]").
- **Интеграция карт**: Использовать ссылки на внешние карты (Google Maps, Apple Maps, 2GIS) для повышения локального авторитета.

## 6. Техническая гигиена
- **Sitemap & Robots**: Автоматическая генерация `sitemap.xml` и `robots.txt` через встроенные файлы/API Next.js (`sitemap.ts`, `robots.ts`).
- **Canonical Tags**: Каждая страница должна иметь `canonical` URL для предотвращения дублей.
- **Hreflang**: Указывать альтернативные языковые версии страниц для корректного переключения в поиске.
