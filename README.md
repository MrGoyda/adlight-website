# ADLight — Корпоративный сайт и Калькулятор (Next.js)

Веб-платформа для производственной компании наружной рекламы в Астане.
Комплексное решение: от портфолио реальных кейсов до автоматического расчета сметы.

## 🚀 Текущий статус: Stage 25 (Refactoring & Scale Update - Dev Branch)

Запущен масштабный рефакторинг и крупное обновление веб-платформы на тестовой ветке `dev`.

### ⚡️ Ключевые изменения

1.  **Calculator SEO & Logic:**
    * Обновлены цены на осень 2025 (см. таблицу ниже).

2.  **Contacts & Local SEO:**
    * Адрес обновлен на: **г. Астана, ул. Аспара 7**.

3.  **Global Optimization:**

## 🗺 Структура проекта

### Основные разделы
* `/` — Главная (Лендинг с преимуществами и картой).
* `/portfolio` — Галерея работ с фильтрацией по категориям.
* `/design-code` — Гайд по требованиям Астаны (штрафы, правила).
* `/contacts` — Карта проезда (Аспара 7) и реквизиты.

### Сервисы (`/services`)
* `volume-letters` — Хаб объемных букв.
* `lightboxes` — Световые короба.
* `neon` — Гибкий неон.
* `roof-installations` — Крышные установки.
* `entrance-groups` — Входные группы.
* `pylons` — Стелы и Пилоны.
* `panel-brackets` — Панель-кронштейны.
* `interior` — Интерьерные логотипы.
* `navigation` — Навигация.

## 🛠 Технический стек

* **Framework:** Next.js 14 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Animation:** Framer Motion / AOS
* **SEO:** Next SEO (Metadata), JSON-LD Schema
